# Elixir · drink-elixir

The Elixir website (Next.js, deployed on Vercel) and the E&T carton artwork.

**Start with [HANDOFF.md](HANDOFF.md).** It covers how the site is built, the brand system, checkout and sign-ups, the next jobs, and the packaging files.

```bash
npm install
npm run dev   # http://localhost:3000
```

- Live: https://elixir-lac-pi.vercel.app
- Carton print files: `packaging/et-4pack/`
